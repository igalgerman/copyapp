# CopyApp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. Model per task is given in each header (Opus = hard/security/UI, Sonnet = medium, Haiku = simple).

**Goal:** Windows exe + Android PWA to move text, images and files between PC and phone over the LAN.

**Architecture:** One Go binary serves an embedded PWA over HTTPS on the LAN, holds a small in-memory outbox, and talks to the Windows clipboard. Phone authenticates with a session cookie obtained by scanning a QR code with a one-time token.

**Tech Stack:** Go 1.22+, `golang.design/x/clipboard`, `golang.design/x/hotkey`, `github.com/getlantern/systray`, `github.com/skip2/go-qrcode`, stdlib `crypto/tls`/`net/http`/`embed`. Vanilla HTML/CSS/JS PWA (no build step).

**Spec:** `docs/superpowers/specs/2026-10-15-copyapp-design.md`

## Global Constraints
- LAN only; no cloud/relay/accounts; single paired phone.
- Single exe, no installer, no runtime deps; PWA embedded with `go:embed`, no JS build step.
- Max item size 200 MB; items expire after 10 min; pairing window 2 min; token 256-bit, single-use.
- Session cookie: HttpOnly, Secure, SameSite=Strict. All endpoints except `/pair`, `/ca.crt`, and static PWA shell require it.
- Received files go to `%USERPROFILE%\Downloads\CopyApp`; never overwrite, never allow path traversal.
- Reject non-private source IPs.
- Ctrl+Alt+C = send PC clipboard to phone.

## Review Focus
- Filename `..\..\x.exe`, `CON`, `a/b`, empty, or 500-char name from phone → sanitized, saved inside the folder.
- Second use of the same pairing token, or token after 2 min → rejected.
- Upload larger than 200 MB → rejected early (413), nothing left on disk.
- Phone sends empty text or clipboard image that is not PNG → clear error, PC clipboard unchanged.
- Request from public IP or with no/forged cookie → 401/403.

### Task 4: HTTP server (Opus)
**Files:** Create `internal/server/server.go`, `internal/server/server_test.go`
**Interfaces:** Consumes `auth.Auth`, `store.Store`, `pc.Clipboard` (interface: `SetText(string)`, `SetImagePNG([]byte) error`, `Notify(title, msg string)`). Produces `New(cfg Config) http.Handler` with `Config{Auth, Store, Clip, SaveDir string, CAPEM []byte}`.
Routes: `GET /` + static (public), `GET /ca.crt` (public, only while pairing open), `GET /pair?t=` (exchange token → set cookie → redirect `/`), `POST /send` (text JSON `{"text":""}` or multipart `file`; 200 MB `MaxBytesReader`), `GET /events` (SSE of outbox items as JSON), `GET /item/{id}` (data), `POST /unpair`. Middleware: private-IP only (RFC1918 + loopback + link-local), cookie required for everything except public routes.
- [ ] **Step 1: Failing tests (httptest, fake Clip):** no cookie → 401; public `RemoteAddr` 8.8.8.8:1 → 403; `/pair` with valid token sets cookie then `/send` text calls `Clip.SetText`; empty text → 400 and no clipboard call; multipart non-image file is saved in SaveDir and not placed on clipboard; image/png upload calls `SetImagePNG`; body > limit → 413; second `/pair` with same token → 401.
- [ ] **Step 2:** Run → fail. **Step 3:** Implement. **Step 4:** Run → pass.
